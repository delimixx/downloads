# Security policy

Please report a vulnerability **privately**. Do not open a public issue.

- Use **Security > Report a vulnerability** in this repository, or
- write to **security@delimixx.com**.

Include the version (*Settings > App Information > Copy Environment Info*) and the steps to reproduce the problem. Do not send private data.

You can write in English or Japanese. We read every report but cannot promise a reply time. A fix is released as a new patch version and noted in the [changelog](https://delimixx.com/en/changelog/).

The machine-readable contact is at https://delimixx.com/.well-known/security.txt.
